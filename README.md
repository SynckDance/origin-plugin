# ORIGIN for Claude Code

The Claude Code plugin for [The Origin Record](https://theoriginrecord.com): a record of how your
ideas develop when you work with AI.

```
/plugin marketplace add SynckDance/origin-plugin
/plugin install origin@origin
/origin:connect
```

`/origin:connect` opens theoriginrecord.com so you can approve this computer. No token is shown or
pasted. Details are in [plugins/origin/README.md](plugins/origin/README.md).

This repository holds the plugin only. ORIGIN itself runs at theoriginrecord.com.
