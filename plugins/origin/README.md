# ORIGIN for Claude Code

Records how your ideas develop while you work with Claude Code, into your account at
theoriginrecord.com.

- **Install:** in Claude Code, `/plugin marketplace add SynckDance/origin-plugin`, then `/plugin install origin@origin`.
- **Connect:** `/origin:connect`. Approve the code it shows at theoriginrecord.com. No token is ever
  shown or pasted.
- **What it records:** the first message of each fresh session, with its text, when nothing came
  before it in that session. If you turn it on, every turn after that as a fingerprint only, with
  the text kept on this computer. And whatever you or Claude send through ORIGIN's tools on purpose.
- **Controls:** `/origin:status`, `/origin:pause`, `/origin:resume`, `/origin:disconnect`. The hook
  prints nothing and never changes or blocks your prompts.
- **What a record establishes:** that this text arrived at this point of a Claude Code session, at
  ORIGIN's time. Never who composed it.

You need an account at theoriginrecord.com. Your record and everything in it stay in your account; this
plugin sends nothing anywhere else.
